The use of + sign:
    If +model_name -> it builds all its dependencies first before compiling this model (model+parent)
    If model_name+ -> it also builds downstream models after it is compiled. (model+children)
    If +model_name+ -> builds parent, this model and children

Materialization
===============
view, table
[i] Modify job_postings.sql and add:
    {{ config(materialized='table') }}
> dbt run
> duckdb ..\data\dev.duckdb
    > .timer on
    > select * from job_postings

Update the dbt_project.yml (to materialize into tables, and the job_postings into a view)
    models:
        analytics:
            +materialized: table

Materialization types:
1. ephemeral -> nothing built - becomes as cte downstream
2. incrementail -> only adds what's new.
3. materialized_view
